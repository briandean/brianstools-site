Network Toolbox

Brian’s Tools

A local, lightweight network toolkit for Windows, macOS and Linux. Subnet math, DNS, ping, traceroute, whois, route tables, IRR and RPKI prefix filters, MAC lookups, time zones and log timestamps — 17 everyday tools for network engineers, in one small desktop app that runs on your own machine.

Version 0.2026.1011 · released October 11, 2026 · No account, no telemetry, no ads

Local

Runs on your computer with no account, telemetry or ads. Calculators, Compare, Log Times, Route Table and Bandwidth Cost work fully offline; the rest only contact the servers you point them at. What it connects to

Lightweight

Built on the Python standard library and shipped as one standalone app per platform. The help is built in (F1), and your favorites, tabs and settings are remembered.

Made for the job

Paste show output, firewall logs or AS paths and the tools pick out what they need. Right-click → Send to moves anything between tools, and every Copy gives neatly aligned text for tickets.

Highlights

Some of the heavier lifting the toolbox does.

Route Table

Paste show ip route or show route from IOS, IOS-XE, IOS-XR, NX-OS, Junos or EOS. Get routes by protocol, interface and next hop, ECMP, recent changes and suspicious metrics.

IRR / RPKI

Expand AS-SETs from the IRR like bgpq4, validate every route object against RPKI, and output prefix filters for IOS-XR, IOS-XE / NX-OS, Junos, EOS and Nokia SR OS / SR Linux.

Bandwidth Cost

Cost per Mbps, per Gbps, per user and per GB moved, with install costs spread or up front, and a saved table for comparing quotes.

Send to

Right-click any IP, MAC, host name or table cell and send it to another tool, which runs it straight away.

17 tools, one window

Start from the Home tab, star the ones you use as favorites, and find the rest in the ☰ Tools menu.

IP

  • IP CalcIPv4/IPv6 subnet math, splits, multicast details and copy-ready subnet summaries for tickets.
  • IP SummarizeCollapse prefixes, ip/mask pairs or ranges into the minimal aggregate and covering supernet.
  • Bits & BytesExact unit conversion across bits, bytes and kilo through peta, in binary or SI.
  • Bandwidth CostWhat a circuit really costs per Mbps, per Gbps and per user, with a saved quote comparison.

Time

  • Time ZonesConvert one time into every zone on your list, with DST gaps and overlaps flagged.
  • Time CalcAdd or subtract calendar time, count business days, repeat intervals, get epochs.

MAC

  • MAC FormatPull MACs out of any pasted text and rewrite them dotted, dashed or colon-separated.
  • MAC LookupVendor lookup from the IEEE list (downloaded for you), plus HSRP, VRRP, GLBP and multicast MACs.

Text & logs

  • CompareSide-by-side and unified diffs of configs, with noise filters and unique-line views.
  • Log TimesFind every timestamp in a log and rewrite it into another time zone in place.

Network

  • DNS DigrBuilt-in dig-style DNS client: full trace from the root, DNSSEC, TCP, every common record type.
  • PingPing up to 256 hosts at once with live loss, RTT, jitter, outages, notes and full history.
  • Ping SweepSweep subnets, ranges or pasted ARP output and see what’s alive in seconds.
  • TracerouteLive hop table from the system traceroute, with address types, loss and MPLS labels.
  • WhoisARIN IP/ASN lookups, AS-path owners, other RIRs via RDAP, and domain whois.
  • Route TablePaste show ip route / show route from IOS, XR, NX-OS, Junos or EOS and get the summary.
  • IRR / RPKIbgpq4-style prefix filters from the IRR with RPKI validation, for XR, XE, Junos, EOS and Nokia.
