0.2026.1012.2 — October 12, 2026

New

  • PeeringDB tool (Network group). Look up a network by ASN, a PeeringDB link (/net/, /ix/, /fac/, /org/), an exchange peering IP, or part of a name.
    • Networks are laid out like peeringdb.com: organization, ASN, IRR as-set, traffic and scope, peering policy, contacts, public peering exchange points and interconnection facilities.
    • Exchanges, facilities and organizations open the same way, with their peers, facilities, prefixes and networks.
    • An exchange IP lookup finds the network on that port and highlights the row.
    • View on PeeringDB ↗ opens the record on the website. PeeringDB names in the results open inside the tool, with ◀ Back to return.
    • Right-click a row to open it on the website, run Whois or IRR / RPKI on the ASN, or ping or copy the IPs.
    • Optional PeeringDB API key for a higher rate limit and logged-in-only contacts. The key is only sent over verified HTTPS.
  • Team Cymru lookups in Whois, now the default source. IPs, prefixes and ASNs go to Team Cymru's IP to ASN mapping service in one bulk query. Results show the origin AS, BGP prefix, AS name, country, registry and allocation date.
    • Choose Auto (whois on TCP 43, falling back to DNS if port 43 is blocked), whois or DNS.
    • Addresses that aren't announced in BGP show in grey, and prefixes with several origin ASes show in orange.
    • Open in bgp.he.net for the selected item.
  • Resizable text boxes and tables. Every box and table in the tools has a grip underneath: drag it to set the height, or double-click it to go back to automatic. Heights are remembered between launches.

Changed

  • Whois has a Source choice: Team Cymru (default) or ARIN and the other registries (RDAP). ARIN mode is unchanged and still gives net names, organizations and abuse contacts. ARIN handles (NET-…, GOGL) always go to ARIN.
  • In the help and README, the "Team Cymru" name links to their website.
  • The help and README cover the new tools.

Fixed

  • Whois over DNS: a resolver that blocks or rewrites lookups no longer makes every address look "not announced". The app first checks a record that always exists, and reports when DNS looks filtered.
  • Help file: a numbered list right after a bulleted list is no longer merged into it.
  • PeeringDB tool: the text panes are sized to the longer column, so the right column is no longer cut off.

Under the hood

  • New modules: cymru.py (Team Cymru client) and peeringdb.py (PeeringDB client).
  • The shared HTTPS helper accepts extra headers and never falls back to an unverified connection when a credential is attached.
  • 105 unit tests.
